# Thatcham Catholic Hall — concept site

An unsolicited concept redesign built by WebDevCo to show what a modern site
for the hall could look like. **Not the hall's official site, not affiliated
with or endorsed by the parish.**

Contact details on the page are placeholders (`[Hall address]` etc.) and the
photos are illustrative gradients — real details and photos would only go in
if the hall took the site on. The page is `noindex` so search engines skip it.

Built from `templates/community-site/` in the WebDevCo repo; deployed by
GitHub Actions to Pages on every push.
